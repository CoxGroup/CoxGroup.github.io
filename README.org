#+TITLE: Cox Group Website
#+OPTIONS: num:nil toc:nil 

The website is organized in a series of =.org= files. The main
homepage is contained in [[file:./content/index.org][=./content/index.org=]]. Subpages are found in,
e.g., [[file:content/publications.org][=./content/publications.org=]]. All images are found in
[[file:./content/images/][=./content/images/=]] under the appropriate subdirectory.

The style of the website is determined by the content in
[[file:content/style.css][=./content/style.css=]], and how the website is publised is controlled
by [[file:publish.el][=./publish.el=]].

To work on the website locally, first clone:

#+begin_src sh
git clone https://github.com/coxgroup/coxgroup.github.io.git
cd coxgroup.github.io.git
#+end_src

After making changes, the website can be built:

#+begin_src sh
emacs --batch -Q -l publish.el --eval '(org-publish "coxgroup" t)'
#+end_src

This will create =./docs/index.html=, which can be opened in a
browser.

Before pushing to =GitHub=:

#+begin_src sh
touch docs/.nojekyll
#+end_src
